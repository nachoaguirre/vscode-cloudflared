# Changelog

## 0.1.0

Initial release.

- Guided setup: detects `cloudflared`, downloads the official release for your platform, or installs via Homebrew / winget / apt / dnf, or uses a binary you point to.
- Browser-based sign-in flow with progress and recovery.
- Quick tunnels for any local port, with detection of ports listening on the machine.
- Named tunnels: create, route DNS, start, restart, stop, delete, change origin; remembers the origin per tunnel.
- Token tunnels for dashboard-managed connectors; tokens stored in the OS keychain.
- Tunnels view, status bar item with quick menu, per-tunnel log channels.
- Getting Started walkthrough, English and Spanish UI.
